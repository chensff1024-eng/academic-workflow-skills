# Output contract

The generated packet is a research aid, not a substitute for reading sources.

## Evidence levels

- `abstract-backed`: an abstract or user note is available. Synthesis may
  paraphrase only what that supplied text supports.
- `metadata-only`: title and bibliographic fields only. Use for discovery and
  classification; do not state the work's argument, method, sources, or result.

## Required separation

Every review should distinguish:

1. supplied evidence;
2. the reviewer's synthesis or comparison;
3. uncertainty and unresolved source checks;
4. recommended next searches.

Never fabricate quotations, page numbers, archival references, publication
status, database indexing, or causal claims. Cite the original work according
to the user's required style after source inspection.
