# Security policy

## Supported versions

Security and privacy fixes are applied to the current default branch.

## Reporting

Open a GitHub security advisory for suspected credential exposure, unsafe
automation, path disclosure, or packaged private data. Do not paste live
credentials, session links, manuscripts, or restricted documents into a
public issue.

## Data boundary

Both bundled tools are local-only and use the Python standard library. They do
not require secrets. A release containing credentials, browser-session access,
document-download automation, or private source artifacts is invalid.
